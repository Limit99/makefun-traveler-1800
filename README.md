# The Glowing Box

A tiny Node/TypeScript program for the make.fun bounty "One Sentence for a Traveler from 1800". It writes one sentence explaining the modern internet to a traveler from 1800 to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> The internet is a library, post office, town square, and theatre stacked inside a glowing box — and you can visit all of it without leaving your chair, mostly while arguing with strangers.

Run it with: `node main.ts`
